01 // O Problema

A maioria dos brasileiros não sabe para onde vai o seu dinheiro.

Faltando dias para o fim do mês, a conta já está no vermelho — e ninguém consegue explicar como. Essa não é uma falha de caráter, é ausência de ferramentas.

"70% dos brasileiros não têm controle financeiro e vivem no limite do orçamento."— CNDL / SPC Brasil, 2024

Gastos invisíveis

Assinaturas esquecidas, parcelas acumuladas e compras por impulso drenam o orçamento sem que você perceba.

Falta de visão do todo

Com múltiplas contas, cartões e aplicativos, é impossível ter uma visão unificada das suas finanças.

Metas que nunca saem do papel

Sem acompanhamento contínuo, sonhos como viagens, reservas e conquistas ficam sempre para o próximo mês.

05 // Grupos & Famílias

Prosperidade compartilhada

Crie grupos familiares, divida despesas com amigos ou colegas — cada um mantendo a privacidade dos seus dados.

Conexões por código

Conecte-se com amigos ou familiares usando um código único aleatório. Sem compartilhar dados pessoais.

Grupos com múltiplos membros

Crie grupos como "Família" ou "Amigos". Cada lançamento pode ser vinculado ao grupo para acompanhamento coletivo.

Dashboard do grupo

Veja despesas por pessoa com gráficos e lista de transações — filtrado por mês, sincronizado a cada 10s.

Privacidade com RLS

Row Level Security garante que dados individuais ficam protegidos. Cada um vê apenas o que é compartilhado.
